# 🚀 Dharanidharan Portfolio

My personal developer portfolio built with **Next.js** and **Tailwind CSS**, featuring a modern UI, dark/light mode, animations, responsive design, and **MERN stack features** with backend APIs and email integration using **Nodemailer**.

---

## ✨ Features

- 🌗 Dark / Light theme toggle
- ⚡ Smooth animations and micro-interactions
- 📱 Fully responsive across all devices
- 🧩 Clean, reusable component architecture
- 📄 Resume view & download functionality
- 📬 Contact form with email delivery using Nodemailer
- 🔒 Scalable MERN-stack ready backend structure

---

## 🛠 Tech Stack

### Frontend
- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Shadcn/UI**
- **Lucide Icons**

### Backend / Integrations
- **Node.js**
- **Express.js**
- **MongoDB**
- **MERN Stack Architecture**
- **Nodemailer** (Email service)
